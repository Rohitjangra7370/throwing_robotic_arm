# Kinova Gen3 7-DoF robot model

Third-party robot description, vendored so the simulation does not depend on files
that exist only on one developer's machine. Not covered by this repository's AGPL-3.0
license: it is © 2018 Kinova inc. under the BSD-3-Clause terms in `LICENSE` here.

**Source:** [`Kinovarobotics/ros_kortex`](https://github.com/Kinovarobotics/ros_kortex),
`kortex_description/arms/gen3/7dof/` (branch `noetic-devel`, checked 2026-10-16),
robot `GEN3-7DOF-VISION_ARM_URDF_V12`.

| File | Relation to upstream |
|---|---|
| `meshes/*.STL` (8 files) | **Byte-identical** to `.../gen3/7dof/meshes/`, verified by SHA-256 on 2026-10-16 |
| `gen3.urdf` | Upstream `urdf/GEN3-7DOF-VISION_ARM_URDF_V12.urdf` with two edits (below) |

Edits to the upstream URDF (48 changed lines in total, all of these two kinds):

1. Mesh URIs rewritten from `package://kortex_description/arms/gen3/7dof/meshes/X.STL`
   to the relative `meshes/X.STL`, because PyBullet has no ROS package resolver.
2. Joints 1, 3, 5, 7: `type="continuous"` with no position limit became
   `type="revolute"` with `lower="-6.28" upper="6.28"`. Effort and velocity limits
   (39/39/9/9 Nm; 1.3963/1.3963/1.2218/1.2218 rad/s) are unchanged.

**Install:** the code loads this model as `pybullet_data/kinova_gen3/gen3.urdf`, from
inside the installed `pybullet_data` package, which the stock `pybullet` wheel does not
ship. Run `python3 scripts/install_robot_assets.py` once per Python environment.

The UR7e model is not vendored; it is generated by `scripts/install_ur7e_urdf.sh`
(needs ROS 2 Humble's `xacro`). The 12 UR7e tests skip with a message until it is
installed.
